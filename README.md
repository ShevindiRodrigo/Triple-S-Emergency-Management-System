## Project Overview

This project was developed as part of the INFO6030 - Systems Analysis and Design course at the University of Newcastle. It proposes the design of an advanced **Emergency Control System** for the city of Nuvalis. The system—named **Triple S (Sensing, Sending, Saving)**—aims to streamline emergency reporting, response dispatching, and incident tracking through a robust and intuitive management solution.

## Key Features

- 📍 **Emergency Location Tracking:** GPS, address-based, and sensor-based alerting.
- ☎️ **Emergency Reporting Module:** User interfaces to capture real-time emergency reports.
- 🚑 **Automated Dispatching:** Determines appropriate services and nearest dispatch center.
- 👥 **Operator & Roster Management:** Manager functionalities to edit operators and assign rosters.
- 🧭 **Sensor Management:** Dynamic sensor addition and maintenance for improved responsiveness.
- 🖥️ **User-Friendly Interfaces:** Designed with Justinmind for accessibility and real-time interaction.

## System Design Highlights

- 📐 **UML Diagrams:** Includes class diagrams, sequence diagrams, and use case descriptions for each subsystem.
- 🧩 **MVC Architecture:** Implements three-layered MVC for modularity and scalability.
- 🔁 **Observer Pattern:** Used in roster creation and operator availability tracking for real-time updates.
- 🔐 **Security & Compliance:** Business rules ensure data privacy, secure access, and adherence to NSW regulations.

## Technologies & Tools

- UML Design Tools (StarUML / Lucidchart)
- Justinmind for UI Prototyping
- Microsoft Teams & MS Project for team collaboration and task tracking

## Deployment Strategy

- 🧪 **Phased Deployment:** Pilot testing followed by controlled rollouts.
- 💾 **Data Migration Plan:** Includes cleansing, backup, and verification.
- 🎓 **User Training:** Role-specific guides, hands-on sessions, and documentation.
- 🐞 **Bug Reporting System:** In-built issue reporting with regular updates and testing.

## Project Management

- 📅 Weekly meetings and Gantt chart planning
- 📝 Documented meeting minutes for transparency and accountability
- 📊 Roles assigned based on team strengths and use case complexity
